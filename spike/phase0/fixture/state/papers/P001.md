## 主要内容

在插孔与拧盖两类接触密集任务上，系统比较了 action chunk 的时间粒度
（50ms / 100ms / 200ms / 400ms）对成功率的影响，控制数据量与网络容量不变。

## 关键结果

- 从 400ms 缩到 100ms，插孔成功率从 41% 提升到 68%。
- 从 100ms 再缩到 50ms，提升明显放缓（68% → 71%），但**接触发生后的
  前 3 个时间步**的动作误差显著下降。
- 在非接触密集任务（取放、推动）上，粒度变化几乎无影响。

## 局限

- 只在两类任务上做，泛化性未知。
- 未与增加数据量的做法做等算力对比。
